## Q1 教师管理端形态【已定：B 小程序教师模式】

> **已定 B**；下面的选项与推荐仅保留决策历史，实施以 [frontend-requirements.md](frontend-requirements.md) §4.3 / §6 为准。

**背景**：蓝本中老师后台是飞书多维表格，天然是桌面端。若放进微信小程序，批阅（多图对比、长评语）、排课日历、台账表格、看板都会很难用。

**选项**
- A. 独立 Web 管理端（`apps/admin`，Vue3 + Vite + TS + Naive UI），小程序只服务家长 —— 历史选项，已被否决

**推荐理由**：批阅与台账是高频重操作，桌面端效率高一个量级；家长端可保持轻量、审核简单。代价是多一个前端工程与一套部署。

**影响**：A 需要新增 `apps/admin`、管理端登录与权限、独立构建产物；B 需要在小程序内做角色路由与更复杂的页面适配。
